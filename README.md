## 💻 O Projeto

Repositório dedicado à prática de **JavaScript** além do que os cursos oferecem. Conforme eu avançava nos estudos, senti necessidade de treinar mais, então pedi para duas IAs diferentes — **Claude** e **GPT** — gerarem listas de exercícios sobre os mesmos tópicos, o que também permite comparar como cada uma aborda a progressão do conteúdo.

Os principais destaques do desenvolvimento incluem:

1. **Organização por origem e tópico:** os exercícios ficam separados nas pastas `/claude` e `/gpt`, cada uma dividida em subpastas numeradas por tema (variáveis, operadores, condicionais, funções etc.), facilitando comparar as duas abordagens lado a lado.
2. **Resolução comentada:** cada `script.js` traz observações próprias sobre o comportamento da linguagem — como a diferença entre `var`, `let` e `const`, coerção de tipos e escopo de bloco — registrando o raciocínio por trás de cada resposta, não só o código.
3. **Progressão:** os exercícios vão cobrir desde os fundamentos até partes avançadas, incluindo mini-projetos aplicados para fixar o conteúdo.

## 🚀 Tecnologias

* **JavaScript (ES6+):** Lógica de todos os exercícios, com uso de `let`/`const`, template literals, arrow functions e métodos nativos de string/number.
* **HTML5:** Estrutura mínima em cada pasta apenas para carregar o `script.js` e permitir a execução no console do navegador.
* **Git & GitHub:** Versionamento e organização do histórico de prática.

## 📁 Estrutura

```
javascript-exercicios/
├── claude/
│ ├── 1-variaveis-constantes/
│ ├── 2-expressoes-operadores/
│ ├── 3-condicionais-fluxo/

└── 1-variaveis-tipos-dados/
```

Cada subpasta contém um `index.html` (carrega o script) e um `script.js` (exercícios resolvidos e comentados daquele tópico).
